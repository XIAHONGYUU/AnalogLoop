# PUBLICATION_GATE

This repository is public by design, but not everything from the working
discussion is public. This file records the publication boundary.

## Approved for public release

- `README.md` and `docs/` text.
- `diagrams/*.svg` and `diagrams/png/*.png` generated by this repository.
- `spec/` contracts and schemas.
- `examples/` synthetic or open-PDK examples.
- Links to public papers, projects, and tools.

## Not approved for public release

- The original architecture image supplied in the design discussion.
- Any commercial PDK model, extracted table, or process data under NDA.
- Customer designs, netlists, or measured silicon data.
- Internal review comments, credentials, or absolute local paths.

## Release checklist

- [x] No image from the original discussion is present.
- [x] No NDA / proprietary PDK data is present.
- [x] `python scripts/validate.py` passes.
- [x] `python scripts/build_diagrams.py` regenerates the same figures.
- [x] `docs/evidence-boundaries.md` is up to date.
- [x] `CITATION.cff` version and date match the release.
- [x] Git history contains no secrets or large binaries.
